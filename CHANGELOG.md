# Changelog

All notable changes to fennec-ui, the shared native UI crate (built on gpui-kit)
that the Fennec desktop shell consumes: timeline grouping, the confirmation and
composer shapes, the delivered-file chip, and the plugin registry. The rule this
repo lives by: code two or more repos need lives here once, kept at MVP, with
capabilities registered through `fennec_ui::plugin` rather than hard-coded.

There are no published releases and no tags in this repo (`git tag --list` is
empty on `Liso7150/fennec-ui`), so nothing below shipped as a numbered release;
the whole history is open work feeding the suite's 1.0.0. Dates are commit dates.

### Added
- The crate itself (`4c5c23d`, 2026-11-18): theme presets, the markdown
  rich-block splitter, message widgets, and the workspace-creation dialog, as
  one gpui-kit library instead of per-shell copies (`src/theme.rs`,
  `src/markdown.rs`, `src/widgets.rs`, `src/workspace_dialog.rs`)
- The shared composer/controls layer and the plugin registry (`4fe223f`):
  permission and model dropdowns, reasoning-effort levels, queue/message widgets
  on theme colours, and the `Plugin` record every capability is declared in
  (`src/controls.rs`, `src/plugin.rs`)
- The inspectable right-panel inspector (`60fd64a`): expandable rows,
  open-in-browser link extraction, thread-local expansion state (`src/inspector.rs`)
- The shared delivery vocabulary (`d2321b2`): the My Attention model — approval
  decisions, risk parsing and colours, the call blob a row expands to, and the
  delivered-file chip that replaces restating a written file in prose
  (`src/attention.rs`)
- Timeline grouping: a run's settled tool calls fold into two expandable blocks
  (`7d11dd9`), then one action block per stretch between answers, so both shells
  price a block identically (`Ran n tools · read n files · wrote n files`)
  (`787c60c`) — `src/timeline.rs`
- The consolidated shapes move (`ce987e3`, 2026-11-21): timeline, confirmation
  (`src/confirm.rs`) and composer now live here so both shells draw the same
  thing; the inspector, theme and widgets grew to carry them
- Grouped timeline rendering shared across surfaces (`b2adf2f`, 2026-11-22)

### Changed
- The shield brand mark replaced with the fennec face drawn in `src/widgets.rs`
  (`be5d6f0`, 2026-11-22)
- `model_dropdown` takes the checkpoint the engine proved it holds (`served`) and
  leads the list with it, so the row a shell can checkmark is the one actually
  answering requests; `model_display_name` passes an unfamiliar served id through
  unchanged instead of dropping the row. Both shells get the same menu from one
  function (`src/controls.rs`, 2026-11-24)

### Fixed

  (`c92ffde`, 2026-11-18)
- Desktop dictation routes through core's STT via the shared control path
  (`276c3a3`, 2026-11-22)
